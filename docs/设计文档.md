### 1.2 分层设计

| 层 | 职责 | 技术 |
|----|------|------|
| **UI 层** | 用户界面、交互逻辑、状态管理 | React + TypeScript + Tailwind CSS |
| **桥接层** | 前后端通信、事件系统 | Tauri IPC (invoke + event) |
| **应用层** | 业务逻辑、命令处理 | Rust (Tauri command handlers) |
| **服务层** | 网络、语音、文件、共享服务 | Rust modules |
| **平台适配层** | 平台特定功能抽象 | Rust `#[cfg(target_os)]` + 原生插件 |
| **基础设施层** | EasyTier 核心引擎、WebRTC | Rust (easytier crate) + webrtc crate |

## 2. 技术选型

### 2.1 后端技术栈

| 组件 | 技术 | 选型理由 |
|------|------|---------|
| 桌面框架 | Tauri 2.x | 跨平台桌面应用，Rust 性能，WebView 渲染 |
| 跨平台运行时 | Rust + Tokio | 异步运行时，高性能，内存安全 |
| VPN 引擎 | EasyTier (crate) | 成熟的 P2P VPN 库，Rust 实现，可直接集成 |
| P2P 通信 | HTTP over EasyTier | 虚拟网络内直接 HTTP 通信，无需额外配置 |
| 实时音频 | WebRTC (webrtc-rs) | 成熟的实时通信方案，支持 P2P 音频流 |
| 屏幕共享 | WebRTC + 平台采集 API | 原生屏幕采集，WebRTC 传输 |
| 文件压缩 | Zstd | 高压缩比，低延迟，Rust 原生支持 |
| 序列化 | Serde + JSON | 标准序列化方案，性能优秀 |
| 本地存储 | SQLite (rusqlite) | 嵌入式数据库，零配置，跨平台 |
| 图像处理 | image crate | 图片压缩、缩略图生成 |
| 二维码生成 | qrcode crate | 空间分享二维码生成 |
| 配置文件 | TOML | EasyTier 原生配置格式 |

### 2.2 前端技术栈

| 组件 | 技术 | 选型理由 |
|------|------|---------|
| 框架 | React 18 + TypeScript | 类型安全，生态丰富 |
| 构建工具 | Vite | 快速开发体验，热更新 |
| 状态管理 | Zustand | 轻量级，无样板代码 |

### 2.3 EasyTier 集成方式

homeTier 将 EasyTier 作为 Rust crate 直接集成，而非通过子进程调用：

```
┌─────────────────────────────────────┐
│          homeTier Backend           │
│  ┌───────────────────────────────┐  │
│  │   EasyTier Crate (library)    │  │
│  │  ┌─────────────────────────┐  │  │
│  │  │ NetworkInstanceManager  │  │  │
│  │  ├─────────────────────────┤  │  │
│  │  │ EasyTierLauncher        │  │  │
│  │  ├─────────────────────────┤  │  │
│  │  │ NetworkConfig           │  │  │
│  │  ├─────────────────────────┤  │  │
│  │  │ RPC Service             │  │  │
│  │  └─────────────────────────┘  │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

关键 API 调用：

```rust
// 创建配置
let cfg = NetworkConfig::new()
    .network_name("my_space")
    .network_secret("secret123")
    .dhcp(true)
    .gen_config()?;

// 启动网络实例
let instance_manager = NetworkInstanceManager::new();
instance_manager.start_instance_task(cfg).await?;

// 获取网络信息
let info = instance_manager.collect_network_infos().await?;

// 停止实例
instance_manager.delete_network_instance(&instance_id).await?;
```

### 3.2 P2P 聊天模块

```
┌──────────────────────────────────────┐
│         P2P Chat Module              │
│                                      │
│  ┌──────────────┐  ┌──────────────┐  │
│  │ Message Bus   │  │ HTTP Server  │  │
│  │ (send/recv)   │  │ (port: auto) │  │
│  └──────┬───────┘  └──────┬───────┘  │
│         │                 │          │
│  ┌──────▼─────────────────▼───────┐  │
│  │  Virtual Network (EasyTier)    │  │
│  │  HTTP over WireGuard tunnel    │  │
│  └────────────────────────────────┘  │
└──────────────────────────────────────┘
```

**通信协议**：
- 每个节点在虚拟局域网内启动 HTTP 服务（随机端口）
- 聊天消息通过 HTTP POST 发送到目标节点的虚拟 IP
- 消息体包含：消息类型、内容、时间戳、签名

**消息格式**：

```json
{
  "type": "text" | "image" | "system",
  "id": "uuid",
  "sender_id": "uuid",
  "sender_name": "string",
  "content": "string (text or base64 image)",
  "timestamp": "ISO8601",
  "signature": "string (HMAC-SHA256)"
}
```

```
│  └───────────────────────────┘       │
└──────────────────────────────────────┘
```

**文件传输协议**：

```
GET /files/{file_id}?token={auth_token}
Host: {virtual_ip}:{port}
Range: bytes={start}-{end}

响应：
- 200 OK: 完整文件
- 206 Partial Content: 断点续传
- 401 Unauthorized: 密码错误
- 404 Not Found: 文件不存在
```

## 4. 跨平台设计

### 4.1 平台抽象层

```rust
// 平台抽象 trait
#[async_trait]
trait PlatformAdapter: Send + Sync {
    /// 创建虚拟网卡
    async fn create_tun(&self, config: &TunConfig) -> Result<Box<dyn TunDevice>>;

    /// 检查是否具有管理员/root 权限
    fn is_elevated(&self) -> bool;

    /// 提权执行
    async fn elevate(&self) -> Result<()>;

    /// 注册系统服务
    async fn install_service(&self, config: &ServiceConfig) -> Result<()>;

    /// 注销系统服务
    async fn uninstall_service(&self) -> Result<()>;

    /// 获取系统日志目录
    fn get_log_dir(&self) -> PathBuf;

    /// 获取配置目录
    fn get_config_dir(&self) -> PathBuf;

    /// 注册全局快捷键
    async fn register_global_hotkey(&self, hotkey: &Hotkey) -> Result<()>;

    /// 注销全局快捷键
    async fn unregister_global_hotkey(&self, hotkey: &Hotkey) -> Result<()>;
}
```

### 4.2 各平台实现

#### Windows

| 特性 | 实现方式 |
|------|---------|
| 虚拟网卡 | wintun.dll (通过 EasyTier 的 tun 模块) |
| 提权 | ShellExecuteW with "runas" verb (UAC 弹窗) |
| 服务管理 | Windows Service API (sc.exe 或 winsvc) |
| 全局快捷键 | tauri-plugin-global-shortcut + Windows Hooks |
| 安装包 | NSIS 或 WiX (.msi) |
| 日志目录 | %APPDATA%/homeTier/logs |
| 配置目录 | %APPDATA%/homeTier/config |
| 额外依赖 | wintun.dll, Packet.dll (打包在资源中) |

#### macOS

| 特性 | 实现方式 |
|------|---------|
| 虚拟网卡 | utun 设备 (通过 EasyTier 的 tun 模块) |
| 提权 | AuthorizationExecuteWithPrivileges |
| 服务管理 | launchd plist 服务 |
| 全局快捷键 | tauri-plugin-global-shortcut + CGEvent |
| 安装包 | .dmg |
| 日志目录 | ~/Library/Logs/homeTier |
| 配置目录 | ~/Library/Application Support/homeTier |
| 权限要求 | 网络权限、麦克风权限、屏幕录制权限 |

#### Android

| 特性 | 实现方式 |
|------|---------|
| 虚拟网卡 | Android VpnService API |
| 提权 | 不需要（VpnService 通过用户授权） |
| 后台运行 | Foreground Service + 通知栏常驻 |
| 生命周期 | 监听 Activity 生命周期，保活策略 |
| 安装包 | .apk / .aab |
| 日志目录 | Context.getCacheDir()/logs |
| 配置目录 | Context.getFilesDir()/config |
| 权限要求 | INTERNET, ACCESS_NETWORK_STATE, FOREGROUND_SERVICE, RECORD_AUDIO, POST_NOTIFICATIONS |
| Rust 集成 | JNI 桥接 (easytier-android-jni 模式) |
| TUN 接口 | 通过 VpnService.Builder 创建，将 fd 传给 Rust 层 |

```rust
// 虚拟网卡创建

fn create_tun_device() -> Result<Box<dyn TunDevice>> { /* wintun */ }

#[cfg(target_os = "macos")]
fn create_tun_device() -> Result<Box<dyn TunDevice>> { /* utun */ }

fn create_tun_device() -> Result<Box<dyn TunDevice>> { /* VpnService fd */ }

#[cfg(target_os = "ios")]
fn create_tun_device() -> Result<Box<dyn TunDevice>> { /* NEPacketTunnel fd */ }

// 提权检查
#[cfg(any(target_os = "windows", target_os = "macos"))]
fn check_elevated() -> bool { /* 桌面端提权检查 */ }

#[cfg(any(target_os = "android", target_os = "ios"))]
fn check_elevated() -> bool { true /* 移动端不需要提权 */ }

// 系统服务管理
#[cfg(target_os = "windows")]
fn manage_service(action: ServiceAction) -> Result<()> { /* Windows Service */ }

#[cfg(target_os = "macos")]
fn manage_service(action: ServiceAction) -> Result<()> { /* launchd */ }

#[cfg(target_os = "android")]
fn manage_service(action: ServiceAction) -> Result<()> { /* Foreground Service */ }

#[cfg(target_os = "ios")]
fn manage_service(action: ServiceAction) -> Result<()> { /* NE VPN */ }
```

## 5. 数据库设计

### 5.1 本地存储结构

使用 SQLite 作为本地持久化存储：

```sql
-- 空间表
CREATE TABLE spaces (
    id TEXT PRIMARY KEY,           -- UUID
    name TEXT NOT NULL,            -- 空间显示名称
    network_name TEXT NOT NULL,    -- EasyTier network-name
    network_secret TEXT NOT NULL,  -- EasyTier network-secret (加密存储)
    description TEXT,
    icon TEXT,
    created_at TEXT NOT NULL,      -- ISO8601
    last_connected_at TEXT,
    is_auto_connect BOOLEAN DEFAULT false,
    config_json TEXT,              -- 群配置 (JSON 序列化)
    local_config_json TEXT         -- 本地配置覆盖 (JSON 序列化)
);

-- 成员表
CREATE TABLE members (
    id TEXT PRIMARY KEY,           -- UUID
    space_id TEXT NOT NULL,        -- 关联空间
    nickname TEXT NOT NULL,
    virtual_ip TEXT,               -- 虚拟局域网 IP
    last_seen_at TEXT,
    is_favorite BOOLEAN DEFAULT false,
    FOREIGN KEY (space_id) REFERENCES spaces(id) ON DELETE CASCADE
);

-- 聊天消息表
CREATE TABLE messages (
```

### 6.1 配置分层模型

### 6.3 配置合并实现

```rust
fn merge_configs(
    group_config: Option<NetworkConfig>,
    local_config: NetworkConfig,
) -> NetworkConfig {
    let mut final_config = NetworkConfig::default(); // 默认配置

    // 1. 应用本地配置
    final_config.merge_from(&local_config, OverrideMode::Local);

    // 2. 应用群配置（覆盖本地配置）
    if let Some(group) = group_config {
        // 安全字段：群配置覆盖
        final_config.network_name = group.network_name;
        final_config.network_secret = group.network_secret;

        // 其他字段：群配置覆盖
        final_config.merge_from(&group, OverrideMode::Group);
    }

    final_config
}
```

## 7. 安全设计

### 7.1 网络安全

- **传输加密**：EasyTier 内置 AES-GCM 或 WireGuard 加密，所有虚拟网络流量加密
- **身份认证**：通过 network-secret（对称密钥）或 credential 模式（公私钥对）认证
- **防重放攻击**：EasyTier 协议包含序列号和时间戳验证
- **中间人防护**：WireGuard 模式使用公钥验证

### 7.2 应用安全

- **敏感数据存储**：network-secret 使用 AES-256-GCM 加密后存储在本地 SQLite
- **消息签名**：聊天消息使用 HMAC-SHA256 签名，防止篡改
- **文件安全**：密码保护文件使用 AES-256-GCM 加密，密码在内存中处理
- **权限控制**：空间 ACL 管理，防止未授权访问

### 7.3 隐私保护

- 不上传用户数据到云端
- 所有通信直连，不经中心服务器
- 可选的匿名模式（不广播设备信息）
