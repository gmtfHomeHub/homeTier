## 1. 项目概述

### 1.1 产品愿景

homeTier 是一款基于 EasyTier P2P 技术的跨平台虚拟局域网应用。用户可以通过创建"空间"（聊天室）来组建虚拟局域网，实现点对点通信、实时语音、文件共享和屏幕共享等功能。每个空间由 EasyTier 的 `network-name` + `network-secret` 唯一标识，用户加入空间后自动获得局域网 IP。

### 1.2 目标用户

- 需要跨地域组建虚拟局域网的游戏玩家
- 远程办公团队，需要安全的内部通信和文件共享
- 开发者和运维人员，需要临时组建安全的点对点网络
- 家庭用户，需要连接不同地点的设备

### 1.3 核心价值

- **零配置**：自动 NAT 穿透，无需公网 IP
- **去中心化**：无中心服务器，节点平等
- **端到端加密**：AES-GCM 或 WireGuard 加密
- **跨平台**：支持 Windows、macOS、Android、iOS

### 2.1 F1 - 虚拟局域网

#### 描述
基于 EasyTier P2P 技术，实现跨网络的直连通信。每个虚拟网络由 `network-name` 和 `network-secret` 唯一标识。

#### 功能规格
- **网络创建**：用户通过输入 network-name 和 network-secret 创建或加入虚拟网络
- **自动 IP 分配**：通过 DHCP 自动分配虚拟局域网 IP（默认 10.126.126.0/24 段）
- **NAT 穿透**：支持 UDP/TCP 穿透，可在 NAT4-NAT4 网络中工作
- **多协议支持**：支持 UDP、TCP、WebSocket、WireGuard 隧道协议
- **智能路由**：延迟优先，自动选择最优路径
- **P2P 直连**：优先直连，失败时通过中继节点转发

#### 验收标准
- [ ] 用户输入 network-name + network-secret 后成功加入虚拟网络
- [ ] 自动获得虚拟局域网 IP（10.x.x.x）
- [ ] 同一网络内的节点之间可以 ping 通
- [ ] NAT 穿透成功率达到 90% 以上（有公网中继节点情况下）

#### 平台差异
| 平台 | 注意事项 |
|------|---------|
| Windows | 需要管理员权限安装虚拟网卡驱动；使用 wintun.dll |
| macOS | 需要 root 权限创建 tun 设备；使用 AuthorizationExecuteWithPrivileges 提权 |
| Android | 需要 VpnService API 创建 Tun 接口；应用内申请 VPN 权限 |
| iOS | 使用 NetworkExtension API 创建虚拟网卡；需要开发者账号和 entitlements |

### 2.2 F2 - 空间管理

#### 描述
用户可以通过 homeTier 创建"空间"（聊天室），每个空间对应一个 EasyTier 虚拟网络。空间可以分享给其他用户。

#### 功能规格
- **创建空间**：用户生成 network-name（自动生成 UUID）和 network-secret，创建空间
- **空间配置**：可设置空间名称、描述、图标、最大成员数
- **空间列表**：展示已创建和已加入的空间列表
- **空间分享**：通过链接或二维码分享空间
- **加入空间**：扫描二维码或点击链接后自动配置 EasyTier 并加入
- **退出空间**：主动退出空间，停止网络连接
- **空间状态**：显示在线成员、网络延迟、连接状态

#### 分享链接格式
```
homeTier://join?name=<network-name>&secret=<network-secret>&host=<host-ip>
```

#### 验收标准
- [ ] 创建空间后自动生成 network-name 和 network-secret
- [ ] 分享链接/二维码可被其他设备识别并加入
- [ ] 空间列表显示所有已加入的空间
- [ ] 退出空间后网络连接断开

### 2.3 F3 - P2P 聊天室

#### 描述
基于 HTTP over WireGuard 的点对点聊天，支持文本和图片消息。

#### 功能规格
- **文本消息**：支持发送和接收文本消息，支持消息历史
- **图片消息**：支持发送图片，自动压缩后传输
- **消息状态**：显示消息发送状态（发送中、已发送、已送达）
- **在线状态**：显示成员在线/离线状态
- **消息通知**：收到新消息时系统通知

#### 技术方案
- 在 EasyTier 虚拟网络上运行 HTTP 服务
- 每个节点既是客户端也是服务端
- 消息通过 HTTP API 在节点间直接传输
- 消息历史存储在本地 SQLite 数据库

#### 验收标准
- [ ] 文本消息在空间内所有成员间实时传递
- [ ] 图片消息可发送并在接收端显示
- [ ] 离线成员上线后能收到历史消息

### 2.4 F4 - 文件共享

#### 描述
基于 HTTP over WireGuard 的高速文件传输，支持批量下载、先压后发、密码保护。

#### 功能规格
- **文件发送**：选择文件发送给空间内成员
- **批量下载**：支持多文件同时下载

- **传输进度**：显示实时传输进度、速度、剩余时间
- **断点续传**：支持大文件断点续传
- **文件管理**：查看已接收文件列表，管理文件存储

#### 验收标准
- [ ] 单个文件可成功传输到目标节点
- [ ] 批量文件传输时显示进度条
- [ ] 压缩传输后文件完整性校验通过
- [ ] 密码保护的文件需要密码才能下载

### 2.5 F5 - 实时语音

#### 描述
内置 WebRTC 语音通话，低延迟、高质量。

#### 功能规格
- **语音频道**：进入空间后自动加入语音频道
- **通话控制**：麦克风静音/取消静音、扬声器静音/取消静音
- **语音激活**：支持语音活动检测（VAD），不讲话时自动静音
- **音量指示**：显示当前说话成员和音量大小
- **回声消除**：内置回声消除和噪声抑制

#### 技术方案
- 使用 WebRTC 进行音频采集和播放
- 通过 EasyTier 虚拟网络建立 P2P 连接传输音频流
- SFU（Selective Forwarding Unit）模式：每个节点发送自己的音频流，接收其他节点的音频流

#### 平台差异
| 平台 | 注意事项 |
|------|---------|
| 桌面端 | 使用 Tauri 的 WebRTC 功能或原生音频 API |
| 移动端 | 使用平台原生 WebRTC 实现，后台音频支持需特殊处理 |
| iOS | 需要在 Info.plist 中声明麦克风权限 |
| Android | 需要在 AndroidManifest.xml 中声明 RECORD_AUDIO 权限，Android 12+ 需要通知栏常驻服务 |

#### 验收标准
- [ ] 同一空间内两个用户可以互相听到对方语音
- [ ] 语音延迟小于 200ms
- [ ] 麦克风静音/取消静音功能正常
- [ ] 回声消除有效

### 2.8 F8 - 聊天室隔离

#### 描述
每个聊天室独立隔离，保护隐私安全。

#### 功能规格
- **网络隔离**：每个空间使用独立的 EasyTier 网络实例
- **数据隔离**：不同空间的聊天记录、文件、连接状态完全隔离
- **成员隔离**：A 空间的成员无法访问 B 空间的任何资源
- **配置隔离**：每个空间有独立的 EasyTier 配置

#### 实现方式
- 使用 `NetworkInstanceManager` 管理多个独立实例
- 每个实例拥有独立的 `network-name` 和 `network-secret`
- 实例间完全隔离，互不干扰

#### 验收标准
- [ ] 同时加入两个空间，A 空间的成员看不到 B 空间的消息
- [ ] 一个空间停止不影响其他空间运行

### 2.9 F9 - 高级网络配置

#### 描述
支持子网代理、网段映射、虚拟域名等高级功能。

#### 功能规格
- **子网代理**：将本地子网（如 192.168.1.0/24）共享给虚拟网络其他成员
- **网段映射**：将虚拟网络 IP 映射到不同网段
- **虚拟域名**：通过 Magic DNS 实现虚拟网络内的域名解析
- **端口转发**：在虚拟网络内配置端口转发规则
- **ACL 访问控制**：配置允许/禁止访问的网络规则
- **退出节点**：将某个节点配置为退出节点，通过该节点访问外部网络

#### 验收标准
- [ ] 子网代理配置后，其他节点可以访问代理子网
- [ ] 虚拟域名解析正确
- [ ] ACL 规则有效限制访问

### 2.12 F12 - EasyTier 配置分级

#### 描述
EasyTier 配置分级控制，优先级：群配置 > 本地配置 > 默认配置。

#### 配置模型

```
优先级高 ──────────────────────────→ 优先级低
  群配置 (Group Config)  >  本地配置 (Local Config)  >  默认配置 (Default Config)
```

- **群配置**：由空间创建者/管理员设置的配置，同步到所有成员
  - `network-name`, `network-secret`
  - 公共节点列表（peers）
  - 监听端口（listeners）
  - 子网代理配置（proxy_cidrs）
  - ACL 规则
  - 加密算法

- **本地配置**：用户本地个性化设置，覆盖群配置中的部分字段
  - `hostname`（节点名称，默认设备名）
  - `dev_name`（虚拟网卡名称）
  - `latency_first`（是否延迟优先）
  - `enable_kcp_proxy` / `enable_quic_proxy`
  - `mtu`（MTU 值）
  - 日志级别

- **默认配置**：EasyTier 内置默认值
  - DHCP = true
  - 默认监听端口（TCP/UDP 11010, WS 11011, WSS 11012, WG 11013）
  - 默认虚拟网段 10.126.126.0/24
  - 默认 flag 值

#### 合并策略
1. 从默认配置开始
2. 应用本地配置（覆盖默认值）
3. 应用群配置（覆盖本地值）
4. 最终合并结果作为运行时配置

#### 验收标准
- [ ] 群配置的 network-secret 不能被本地配置覆盖（安全限制）
- [ ] 群配置更新后，所有在线成员自动同步
- [ ] 本地配置修改后立即生效，不影响其他成员

## 3. 非功能需求

### 3.1 性能要求

| 指标 | 目标值 |
|------|--------|
| P2P 直连延迟 | < 10ms（同城），< 50ms（跨省） |
| 中继延迟 | < 100ms（有公共节点情况下） |
| 语音延迟 | < 200ms（端到端） |
| 文件传输速度 | 达到网络带宽的 80% 以上 |
| 内存占用 | 空闲 < 50MB，运行时 < 200MB（单个网络实例） |
| CPU 占用 | 空闲 < 1%，传输时 < 30% |

### 3.2 安全要求

- **传输加密**：所有网络流量使用 AES-GCM 或 WireGuard 加密
- **身份认证**：通过 network-secret 或 credential 模式认证
- **数据隔离**：不同空间间完全隔离
- **文件安全**：密码保护的文件传输
- **隐私保护**：不收集用户隐私数据

### 3.3 跨平台要求

| 平台 | 最低版本 | 架构 | 安装包格式 |
|------|---------|------|-----------|
| Windows | Windows 10 1809+ | x86_64, arm64 | .msi / .exe (NSIS) |
| macOS | macOS 12+ | x86_64, arm64 | .dmg |
| Android | Android 8.0 (API 26)+ | arm64-v8a, armeabi-v7a, x86_64 | .apk / .aab |
| iOS | iOS 15+ | arm64 | .ipa |

### 3.4 可用性要求

- **自动重连**：网络断开后自动重连
- **崩溃恢复**：应用崩溃后重启自动恢复连接
- **无感升级**：后台自动下载更新，下次启动时安装
- **数据持久化**：配置和聊天记录保存在本地，不丢失
